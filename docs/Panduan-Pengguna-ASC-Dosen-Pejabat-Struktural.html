Akses dan Akun

1. Mengenal ASC, akses, dan akun

ASC adalah aplikasi kampus berbasis web yang menampilkan layanan sesuai peran pengguna.

Alamat aplikasi

https://asc.aljawami.ac.id

Pastikan alamat menggunakan HTTPS dan nama domain tepat. Gunakan jaringan internet yang stabil saat menyimpan, mengirim, menandatangani, atau mengunduh dokumen.

Masuk ke akun

1

Buka alamat ASC, lalu pilih halaman masuk jika belum tampil.

2

Masukkan username/email dan kata sandi yang diberikan atau diatur untuk akun Anda.

3

Pilih Masuk. Setelah berhasil, periksa nama dan peran yang ditampilkan di aplikasi.

Menu berdasarkan tugas

Dosen umumnya menggunakan menu kelas/perkuliahan, RPKPS/RPS, nilai, KRS/perwalian, bimbingan, skripsi, dan layanan pribadi yang diizinkan. Pejabat struktural dapat memperoleh menu tambahan untuk pemantauan, lingkup program/fakultas, persetujuan, kurikulum, laporan, atau penandatanganan.

Akses terbatas: jabatan dan menu bersifat spesifik. Data yang terlihat mengikuti kewenangan serta lingkup kerja akun; tidak semua pejabat melihat semua program studi atau layanan.

Keamanan akun

  • Jangan membagikan kata sandi atau kode autentikasi.
  • Keluar dari aplikasi pada perangkat bersama.
  • Perbarui kata sandi dari profil/pengaturan apabila fitur tersedia.
  • Periksa kembali data dan lampiran sebelum dikirim atau disahkan.

Laptop dan Komputer

2. Instalasi di laptop atau komputer

ASC dapat dipasang sebagai aplikasi web (PWA) dari browser. Pemasangan tidak mengunduh aplikasi dari toko aplikasi.

Microsoft Edge

  1. Buka https://asc.aljawami.ac.id dan masuk.
  2. Pilih ikon App tersedia/Install di bilah alamat, jika muncul; atau buka menu ….
  3. Pilih Apps → Install this site as an app.
  4. Konfirmasi Install. Aktifkan pintasan taskbar/desktop jika diinginkan.

Google Chrome

  1. Buka alamat ASC pada Chrome dan masuk.
  2. Pilih ikon Install di bilah alamat bila tersedia.
  3. Jika tidak muncul, buka menu ⋮ → Cast, save, and share → Install page as app (nama menu dapat berbeda).
  4. Konfirmasi pemasangan. ASC akan muncul sebagai jendela/aplikasi tersendiri.

Jika pilihan Install tidak muncul

  • Perbarui browser, gunakan Chrome atau Edge versi terbaru, lalu kunjungi ulang alamat ASC.
  • Pastikan halaman sudah dimuat penuh dan perangkat terhubung ke internet.
  • Anda tetap dapat menggunakan ASC langsung dari browser tanpa memasangnya.

Catatan: PWA adalah pintasan aplikasi ke layanan web. Login, penyimpanan, dan fitur kampus tetap memerlukan koneksi internet.

Membuka atau menghapus aplikasi

Buka ASC dari Start Menu/daftar aplikasi. Untuk menghapusnya, gunakan pengaturan Apps di Edge/Chrome atau daftar aplikasi Windows; penghapusan PWA tidak menghapus akun ASC.

Android dan iPhone

3. Instalasi di smartphone

Android · Chrome

  1. Buka Chrome, kunjungi https://asc.aljawami.ac.id, lalu masuk.
  2. Ketuk menu ⋮ di kanan atas.
  3. Pilih Install app atau Add to Home screen.
  4. Konfirmasi. Ikon ASC akan muncul di layar utama/daftar aplikasi.

iPhone/iPad · Safari

  1. Buka Safari, kunjungi https://asc.aljawami.ac.id, lalu masuk.
  2. Ketuk tombol Bagikan (kotak dengan panah ke atas).
  3. Gulir pilihan, ketuk Add to Home Screen/Tambahkan ke Layar Utama.
  4. Periksa nama ASC, lalu ketuk Add/Tambahkan.

Menggunakan aplikasi yang terpasang

Ketuk ikon ASC untuk membuka. Jika diminta, masuk kembali dengan akun kampus. Gunakan browser yang sama saat memasang aplikasi untuk hasil terbaik.

Jika instalasi tidak tersedia: gunakan opsi Tambahkan ke layar utama pada menu browser, periksa koneksi, atau buka ASC melalui browser. Hindari memasang aplikasi dari tautan atau toko tidak resmi.

Berbagi perangkat dengan aman

  • Jangan memilih simpan kata sandi pada perangkat milik orang lain.
  • Keluar dari akun setelah selesai.
  • Jangan menghapus data situs jika masih ada formulir yang belum dikirim; simpan dahulu perubahan yang diperlukan.

Beranda dan Informasi

4. Dashboard, kalender, dan notifikasi

Dashboard

Dashboard menyapa pengguna dan memuat ringkasan sesuai peran. Dosen dapat melihat ringkasan kelas, mahasiswa bimbingan, KRS yang menunggu persetujuan, atau pengumpulan tugas. Pejabat dapat melihat jabatan aktif, ringkasan lingkup kerja, dan akses cepat ke layanan yang diizinkan.

1

Gunakan menu kiri (komputer) atau tombol menu (ponsel) untuk membuka layanan.

2

Pilih kartu ringkasan/menu cepat untuk menuju rincian jika tersedia.

3

Gunakan filter semester, status, atau pencarian pada halaman daftar untuk mempersempit data.

Kalender akademik dan agenda

Periksa tanggal kegiatan akademik, periode penting, rapat, undangan, lokasi, dan waktu. Agenda personal menampilkan kegiatan yang relevan dengan akun. Informasi jadwal pada ASC dapat berubah mengikuti pembaruan admin.

Notifikasi

  • Buka menu Notifikasi atau ikon lonceng bila ditampilkan.
  • Perhatikan pemberitahuan baru mengenai persetujuan, bimbingan, surat, atau kegiatan.
  • Ketuk notifikasi untuk membuka data terkait; status baca dapat diperbarui otomatis.

Perlu diperhatikan: angka ringkasan merupakan informasi cepat. Buka halaman rincian sebelum melakukan persetujuan atau mengambil keputusan.

Perkuliahan

5. Kelas, materi, presensi, tugas, dan diskusi

Buka menu Akademik → Penawaran Kelas atau kartu Kelas Saya pada Dashboard. Daftar dan tombol yang tersedia bergantung pada penugasan dosen di kelas tersebut.

Melihat kelas dan jadwal

  1. Pilih semester dan kelas yang diampu.
  2. Buka detail kelas untuk melihat mata kuliah, peserta, jadwal, dan fasilitas.
  3. Gunakan tab kelas untuk berpindah antara jurnal, materi, tugas, presensi, dan fitur pembelajaran yang tersedia.

Jurnal dan presensi

  1. Pilih pertemuan/jurnal yang sesuai dengan jadwal.
  2. Lengkapi topik, materi, metode, dan informasi pertemuan yang diminta.
  3. Simpan; buka kembali untuk memastikan catatan dan status tersimpan.

Materi, tugas, dan diskusi

  • Tambahkan materi atau tautan yang jelas dan relevan pada kelas yang benar.
  • Saat membuat tugas, periksa petunjuk, tenggat, nilai maksimum, dan lampiran sebelum disimpan/dibagikan.
  • Buka daftar pengumpulan, tinjau jawaban mahasiswa, berikan nilai dan umpan balik, lalu simpan.
  • Gunakan diskusi/pengumuman untuk komunikasi pembelajaran; pastikan topik ditautkan ke kelas yang tepat.

Jangan mengisi presensi atau jurnal untuk kelas/pertemuan yang keliru. Koreksi atau perubahan mungkin terbatas setelah data disimpan.

Rencana Pembelajaran

6. RPKPS/RPS dan kurikulum

Menu Kurikulum → RPKPS / RPS Digital membantu dosen menyusun Rencana Pembelajaran Semester (RPS/RPKPS) untuk mata kuliah yang diampu. Dokumen menghubungkan CPL, CPMK, rencana per minggu, asesmen, rubrik, dan referensi.

1

Buka Kurikulum → RPKPS / RPS Digital, lalu cari mata kuliah dan kurikulum yang sesuai.

2

Pilih Buat RPS, pilih mata kuliah yang diampu, kurikulum aktif yang sesuai, dan tahun akademik. Identitas dosen terisi otomatis.

3

Buka detail dan lengkapi tab CPL, CPMK, Deskripsi & Bahan Kajian, Rencana Mingguan, Asesmen, Instrumen & Rubrik, dan Referensi.

4

Simpan tiap tab, periksa kembali dokumen, lalu pilih Ajukan Validasi. Panduan rinci setiap bagian ada di halaman 9–10.

Dosen hanya dapat membuat RPKPS untuk mata kuliah yang ditugaskan kepadanya. Jika mata kuliah tidak muncul, koordinasikan penugasan mengajar dengan Kaprodi/Admin Akademik.

Pejabat struktural: Kaprodi dapat meninjau pengajuan RPKPS, meminta revisi dengan catatan, menyetujui, dan mengunci dokumen sesuai izin.

Panduan Dosen · Identitas dan Capaian

Pembuatan RPKPS/RPS (1)

Membuat dokumen untuk mata kuliah yang diampu

  1. Buka Kurikulum → RPKPS / RPS Digital dan pilih Buat RPS.
  2. Pilih mata kuliah yang ditugaskan kepada Anda. Pilih kurikulum aktif yang memuat mata kuliah tersebut dan tahun akademik yang sesuai. Tahun aktif serta identitas dosen dapat terisi otomatis.
  3. Isi deskripsi awal bila diperlukan, lalu buat dokumen. Pastikan kode/nama mata kuliah, kurikulum, tahun akademik, dan nama penyusun benar.
  4. Jika membuat dokumen baru untuk tahun berikutnya, tombol Gunakan RPKPS Lama dapat menyalin RPKPS yang telah disetujui/dikunci/diarsipkan menjadi draf baru. Pilih tahun tujuan; kurikulum dapat diganti bila relevan. Dokumen lama tidak berubah.

Dokumen yang baru dibuat berstatus DRAFT. Dosen penyusun dapat mengedit saat DRAFT atau REVISI; dokumen DIKUNCI/DIARSIPKAN tidak dapat diubah.

Lengkapi CPL dan CPMK

  • CPL: ditampilkan dari kurikulum dan pemetaan CPL–Mata Kuliah. Dosen memilih/menyinkronkan CPL sesuai dukungan yang sudah ditetapkan kurikulum. Jika daftar kosong, minta pengelola kurikulum memeriksa pemetaan, bukan membuat CPL baru dari halaman RPS.
  • CPMK: pilih tab CPMK, tekan Tambah CPMK, isi kode dan uraian capaian mata kuliah, lalu tautkan ke satu atau lebih CPL yang relevan.
  • Tambahkan Sub-CPMK yang lebih spesifik dan dapat diamati/diukur. Isi kode serta deskripsi; sistem membantu membentuk kode Sub-CPMK berurutan.
  • Pastikan CPMK/Sub-CPMK menjabarkan kontribusi mata kuliah terhadap CPL secara logis dan dapat dinilai. Simpan perubahan dan periksa urutan serta relasinya.

Deskripsi dan bahan kajian

Pada tab Deskripsi & Bahan Kajian, tulis ringkasan ruang lingkup mata kuliah. Pilih mata kuliah prasyarat dari daftar mata kuliah pada kurikulum atau pilih tidak ada prasyarat. Klik Simpan pada tab ini.

Jika kurikulum, CPL, atau mata kuliah tidak tersedia, koordinasikan pembaruan master/kurikulum terlebih dahulu. RPKPS harus merujuk struktur kurikulum yang berlaku, bukan menggantinya.

Panduan Dosen · Rencana, Asesmen, dan Pengajuan

Pembuatan RPKPS/RPS (2)

Rencana pembelajaran 16 minggu

  1. Buka tab Rencana Mingguan. Jika belum ada tabel, tekan Inisialisasi 16 Minggu.
  2. Untuk tiap minggu, tautkan Sub-CPMK, lalu isi indikator, bahan kajian, metode, pembelajaran luring/daring, alokasi waktu, aktivitas dosen, dan aktivitas/pengalaman mahasiswa.
  3. Lengkapi bentuk/teknik penilaian, kriteria, media pembelajaran, dan bobot sesuai rencana. Minggu 8 dan 16 disediakan sebagai evaluasi tengah dan akhir semester.
  4. Geser tabel ke samping untuk melihat semua kolom, kemudian tekan Simpan Rencana Mingguan.

Asesmen, rubrik, dan referensi

  • Di tab Asesmen, tetapkan komponen, keterangan/teknik, dan bobot. Jumlah bobot wajib tepat 100% sebelum dapat disimpan. Lengkapi rumus nilai akhir serta rentang nilai huruf dan bobot mutunya.
  • Di Instrumen & Rubrik, hubungkan instrumen dengan komponen asesmen dan Sub-CPMK; isi teknik, jenis instrumen, ranah, waktu, butir, serta deskripsi bila relevan.
  • Tambahkan rubrik: judul, kriteria, bobot, serta deskripsi tingkat performa. Simpan instrumen dan rubrik.
  • Di tab Referensi, catat referensi utama/pendukung beserta kategori dan informasi bibliografi/tautan yang tersedia. Simpan.

Simpan, ajukan, dan tindak lanjuti

Simpan masing-masing tab setelah perubahan; jangan mengandalkan pindah tab sebagai penyimpanan otomatis. Gunakan Template/Import/Export Excel bila ingin mengisi workbook. Impor memperbarui bagian yang tercantum dan mempertahankan baris yang tidak disertakan. Unduh PDF untuk memeriksa hasil akhir.

Pilih Ajukan Validasi saat siap. Status berubah dari DRAFT menjadi DIAJUKAN; Kaprodi meninjau, menyetujui, atau mengembalikan dengan catatan REVISI. Perbaiki catatan dan ajukan kembali. Setelah disetujui, pejabat yang berwenang dapat mengunci dokumen.

Ajukan hanya setelah CPL–CPMK–Sub-CPMK, rencana mingguan, bobot 100%, rubrik, dan referensi diperiksa. Status terkunci mencegah perubahan.

Penilaian

7. Gradebook dan pengelolaan nilai

Nilai akhir dikelola untuk kelas dan mahasiswa yang menjadi tanggung jawab dosen. Pastikan semester, mata kuliah, dan kelas sudah benar sebelum mengubah data.

Menyiapkan komponen nilai

  1. Buka detail kelas dan tab Gradebook/skema penilaian jika tersedia.
  2. Tambahkan komponen sesuai ketentuan mata kuliah, misalnya tugas, kuis, UTS, atau UAS.
  3. Atur bobot hingga totalnya 100%, lalu simpan dan periksa kembali.

Mengisi atau mengimpor nilai akhir

  1. Buka Akademik → Input Nilai Akhir dan pilih kelas.
  2. Isi nilai komponen yang wajib untuk setiap mahasiswa, atau unduh template dan impor sesuai petunjuk di layar.
  3. Tinjau nilai, kelengkapan, perhitungan, dan pesan validasi. Perbaiki kesalahan sebelum menyimpan.
  4. Pilih Sahkan Nilai Akhir hanya setelah yakin data benar dan proses pengesahan memang menjadi kewenangan Anda.

Total bobot selain 100% atau nilai wajib yang kosong dapat membuat nilai akhir tidak dapat disahkan. Setelah disahkan, perubahan dapat memerlukan kewenangan khusus.

KHS dan transkrip

Menu KHS/Transkrip dapat digunakan sesuai peran untuk melihat ringkasan hasil studi. Pejabat menggunakan informasi tersebut sebagai bahan pemantauan; verifikasi rincian pada data akademik sebelum mengambil keputusan.

Persetujuan Akademik

8. KRS dan perwalian

Dosen wali dan pejabat yang mendapat akses dapat memeriksa pengajuan KRS pada menu Akademik → KRS & Perwalian.

1

Pilih semester atau gunakan pencarian nama/NIM dan status untuk menemukan pengajuan.

2

Buka rincian KRS; periksa mahasiswa, mata kuliah, SKS, kelas, dan jadwal yang ditampilkan.

3

Periksa kelayakan akademik dan informasi yang menjadi tanggung jawab dosen wali/prodi.

4

Jika sesuai, pilih Setujui. Jika perlu revisi, pilih Tolak dan isi catatan yang jelas agar mahasiswa tahu tindak lanjutnya.

Pemeriksaan bentrok: sistem menolak pengajuan bila jadwal aktif pada kelas yang dipilih bertabrakan. Rincian hari, kelas, dan jam ditampilkan pada halaman KRS. Minta mahasiswa mengganti kelas atau menghapus mata kuliah bentrok, kemudian tinjau ulang.

Status dan kewenangan

Status umum mencakup draft, diajukan/menunggu review, disetujui, atau ditolak. Gunakan tombol sesuai status dan kewenangan yang tampil. Jangan membagikan dokumen atau data mahasiswa di luar lingkup tugas.

Kaprodi/Sekprodi dan pejabat lain mungkin memperoleh lingkup data yang berbeda. Jika mahasiswa tidak terlihat, verifikasi semester, status, program studi, dan penugasan dosen wali.

Perwalian Mahasiswa

9. Bimbingan akademik

Jika izin Bimbingan Akademik tersedia, dosen wali dapat mengelola sesi dan catatan pendampingan. Gunakan data ini untuk mendokumentasikan tindak lanjut secara terarah.

Mengelola sesi bimbingan

  1. Buka menu Bimbingan Akademik dan pilih dashboard, sesi, atau mahasiswa bimbingan.
  2. Buka sesi yang diajukan. Periksa nama mahasiswa, topik, waktu usulan, dan informasi pendukung.
  3. Perbarui status sesuai proses pada halaman, misalnya menjadwalkan sesi bila tersedia.
  4. Setelah pertemuan, catat pembahasan dan langkah tindak lanjut pada catatan bimbingan.

Catatan dan peringatan akademik

  • Gunakan menu Catatan Akademik untuk menyimpan catatan yang faktual, relevan, dan profesional.
  • Gunakan Peringatan Akademik hanya bila tugas dan kewenangan Anda mencakup fitur tersebut.
  • Jaga kerahasiaan catatan pribadi; hindari menulis data sensitif yang tidak diperlukan.
  • Periksa kembali mahasiswa dan isi catatan sebelum menyimpan.

Catatan sebaiknya merangkum isu akademik, kesepakatan, penanggung jawab, serta waktu tindak lanjut secara singkat dan jelas.

Pembimbing dan Penguji

10. Skripsi dan tugas akhir

Modul Skripsi/TA memuat alur pengajuan dan pembimbingan mahasiswa. Tampilan tindakan bergantung pada tahap proses dan peran—misalnya pembimbing, penguji, Kaprodi, atau sekretariat.

Meninjau pengajuan

  1. Buka menu Akademik → Skripsi / TA atau notifikasi tugas terkait.
  2. Pilih mahasiswa dan proposal yang tepat; baca judul, dokumen, riwayat, dan status.
  3. Gunakan tindakan review yang tersedia. Bila menolak atau meminta perbaikan, tuliskan alasan/masukan yang spesifik.
  4. Untuk bimbingan, catat bab/kemajuan dan arahan; simpan tautan revisi bila memang diminta.

Seminar, sidang, dan hasil

Jika menjadi kewenangan Anda, gunakan halaman detail untuk menjadwalkan seminar/sidang, memasukkan penilaian penguji, atau mencatat hasil. Pastikan jadwal, peserta, dan peran penguji benar sebelum menyimpan.

Jangan mengubah status hanya untuk melewati tahap proses. Ikuti prosedur prodi, gunakan catatan review, dan simpan dokumen pada mahasiswa yang benar.

Menu LP2M, karya dosen, penelitian, atau pengabdian pada akun struktural merupakan layanan terpisah; lihat bab 11 dan 12.

Kegiatan dan Karya Ilmiah

11. Praktikum, KKN, penelitian, dan karya dosen

Praktikum/KKN/PPL/Magang

Jika dosen berperan sebagai pembimbing/pengelola, buka menu Praktikum / KKN, pilih program, lalu buka rincian peserta atau kelompok. Periksa lokasi, periode, status, logbook, dan bukti yang diperlukan sebelum memberi penilaian atau tindak lanjut. Fitur yang tersedia mengikuti peran yang diberikan.

Penelitian dan pengabdian

Menu Penelitian & Pengabdian atau Hibah Penelitian digunakan jika akun mendapat izin terkait. Periksa periode aktif, data tim, usulan, berkas, anggaran, serta status review. Lengkapi bagian yang menjadi tanggung jawab Anda dan gunakan komentar untuk permintaan revisi.

Karya dosen

Gunakan Karya Dosen untuk mencatat karya sesuai ketentuan institusi. Isi metadata dan penulis dengan tepat, lampirkan berkas utama yang diperlukan, lalu kirim untuk verifikasi bila alur tersebut tersedia.

Unggah berkas: gunakan format/ukuran yang diterima aplikasi, nama file yang jelas, dan pastikan file berhasil terunggah. Buka detail setelah menyimpan untuk memeriksa kembali tautan atau lampiran.

Pejabat yang bertugas menilai/memverifikasi hanya boleh memproses data pada lingkup kewenangannya. Baca status dan riwayat perubahan sebelum memberi keputusan.

Panduan Kaprodi dan Sekretaris Prodi

12. Alur kerja Kaprodi dan Sekretaris Prodi

Gunakan urutan berikut sebagai checklist awal semester. Nama menu dapat berbeda menurut izin akun. Kaprodi dan Sekprodi dapat memiliki hak yang berbeda; tindakan hanya tersedia bila role, izin, dan lingkup prodi sudah ditetapkan.

Persiapan akademik prodi

  • Pastikan program studi dan Kaprodi yang tercatat sudah benar.
  • Periksa master mata kuliah, kode, SKS, dan semester penawaran.
  • Siapkan kurikulum prodi, susunan mata kuliah, dan status kurikulum.
  • Perbarui penugasan dosen PA/wali untuk mahasiswa yang menjadi tanggung jawab prodi.
  • Pastikan kelas, dosen pengampu, kapasitas, jadwal, dan ruangan sudah disiapkan.

Pelaksanaan dan pemantauan

  • Pilih semester dan program studi yang tepat saat meninjau data.
  • Pantau mahasiswa yang mengisi KRS, status pengajuan, jumlah SKS, dan dosen wali.
  • Tinjau bentrok jadwal dan kelayakan sebelum memberi persetujuan.
  • Gunakan ekspor/impor untuk pemeriksaan atau pembaruan massal, lalu baca hasilnya.
  • Gunakan dashboard/laporan sebagai ringkasan; periksa detail sebelum mengambil keputusan.

Urutan yang disarankan: Master Mata Kuliah → Kurikulum OBE dan pemetaan MK → Dosen PA/wali → kelas dan jadwal semester → pemantauan serta review KRS.

Hak akses dan tanggung jawab

Beberapa operasi data induk mungkin hanya muncul untuk Admin Akademik. Fitur Dosen PA massal tersedia bagi Kaprodi dan peran admin tertentu; Sekprodi mungkin memiliki akses pemantauan atau review sesuai konfigurasi institusi. Jangan mengubah status kurikulum, kelas, atau KRS tanpa kewenangan.

Tidak melihat menu/data? Verifikasi semester, prodi, jabatan aktif, dan akun dosen yang tertaut. Minta Admin ASC/Admin Akademik memeriksa izin; jangan menggunakan akun orang lain.

Data Induk Akademik

13. Master data mata kuliah

Master mata kuliah menjadi sumber pilihan saat menyusun kurikulum dan penawaran kelas. Pastikan mata kuliah dibuat pada program studi yang benar sebelum ditambahkan ke kurikulum.

Membuat mata kuliah

  1. Buka Master Data → Mata Kuliah. Jika menu tidak terlihat, minta Admin Akademik mengelola atau memberi akses.
  2. Pilih Tambah MK, lalu isi Program Studi, Kode, Nama Mata Kuliah, dan Jenis: Wajib, Pilihan, atau Praktikum.
  3. Masukkan SKS Teori dan SKS Praktik. Total SKS dihitung otomatis; jumlahnya harus 1–6 SKS.
  4. Pilih semester yang disarankan (1–8), isi rumpun mata kuliah bila diperlukan, lalu tentukan status Aktif.
  5. Pilih pelaksanaan: tatap muka atau non-tatap muka, kemudian simpan.

Arti pelaksanaan: kelas tatap muka memerlukan dosen, jadwal, dan ruangan. Mata kuliah non-tatap muka tidak memerlukan tiga data tersebut saat kelas dibuat.

Memeriksa dan memperbarui

  • Gunakan pencarian kode/nama dan filter program studi atau semester untuk menemukan data.
  • Periksa kode, nama, prodi, total SKS, semester, jenis, pelaksanaan, dan status pada tabel sebelum dipakai di kurikulum.
  • Gunakan tombol edit untuk memperbarui data. Nonaktifkan mata kuliah yang tidak lagi ditawarkan, alih-alih menghapus jika sudah digunakan pada data akademik.
  • Untuk banyak mata kuliah, unduh template dari tombol Excel pada halaman Mata Kuliah, pertahankan nama kolom, lalu impor. Periksa laporan baris yang gagal.

Pastikan tidak membuat kode mata kuliah ganda dan jangan mengubah SKS secara sembarang setelah mata kuliah digunakan oleh kelas atau riwayat studi.

Kurikulum Program Studi

14. Menyusun kurikulum OBE

Kurikulum OBE menautkan profil lulusan, Capaian Pembelajaran Lulusan (CPL), mata kuliah, dan pemetaan kontribusi mata kuliah terhadap CPL.

Membuat kurikulum dan memasukkan mata kuliah

  1. Buka Kurikulum → Kurikulum OBE, lalu pilih Tambah Kurikulum.
  2. Pilih Program Studi. Isi kode kurikulum, nama, tahun, deskripsi bila perlu, serta status. Gunakan status Draft saat masih disusun.
  3. Buka detail kurikulum melalui ikon lihat. Pastikan nama prodi dan tahun kurikulum sudah sesuai.
  4. Kelola bagian Mata Kuliah, pilih mata kuliah master yang akan masuk ke kurikulum, lalu tetapkan semester dan apakah mata kuliah wajib.
  5. Simpan susunan. Periksa jumlah mata kuliah dan semester penempatannya.

Melengkapi komponen OBE

  • Tambahkan Profil Lulusan dengan kode, nama, dan deskripsi kompetensi lulusan.
  • Tambahkan CPL dengan kode dan uraian capaian; hubungkan CPL ke profil lulusan yang relevan.
  • Di matriks CPL–Mata Kuliah, tandai mata kuliah yang berkontribusi pada masing-masing CPL, lalu simpan pemetaan.
  • Gunakan tombol Template untuk memperoleh format workbook, Export untuk mengunduh data, dan Import untuk memuat perubahan.

Impor workbook menambah atau memperbarui baris yang tercantum; data yang tidak ada pada file tidak otomatis dihapus. Tinjau konfirmasi impor, hasil sukses, dan kesalahan sebelum melanjutkan.

Validasi sebelum kurikulum digunakan

Periksa kembali mata kuliah wajib/pilihan, alokasi semester, total SKS, kode, CPL, dan matriks. Status Draft/Aktif/Nonaktif harus mencerminkan keputusan resmi prodi. Kelas baru mengambil mata kuliah dari kurikulum aktif, jadi koordinasikan aktivasi dengan Admin Akademik sesuai prosedur kampus.

Dosen Pembimbing Akademik

15. Penetapan dosen PA/wali

Setiap mahasiswa perlu ditautkan ke dosen PA/wali yang benar agar pengajuan KRS dapat masuk ke antrean dosen yang berwenang. Periksa NIM, NIDN dosen, dan lingkup prodi sebelum memperbarui penugasan.

Impor penugasan secara massal

  1. Buka SDM → Data Mahasiswa menggunakan akun Kaprodi atau admin yang berwenang. Panel Dosen Pembimbing Akademik akan muncul bila akses tersedia.
  2. Pilih Template PA untuk mengunduh workbook contoh. Template memuat kolom NIM, identitas mahasiswa/prodi, NIDN Dosen PA, dan nama dosen.
  3. Isi kolom NIM dan NIDN Dosen PA dengan data yang benar. NIM harus cocok dengan mahasiswa; NIDN harus cocok dengan dosen di data ASC.
  4. Simpan sebagai XLSX/XLS/CSV tanpa mengganti nama kolom wajib. Hindari NIM ganda dalam satu file.
  5. Pilih Import PA dan unggah berkas. Baca pesan jumlah penugasan yang diperbarui serta daftar baris yang tidak diproses.
  6. Jika ada kesalahan, koreksi baris terkait lalu impor ulang. Gunakan Export PA untuk memeriksa penugasan saat ini.

Perhatian: NIDN Dosen PA yang dikosongkan akan melepas penugasan dosen pada mahasiswa tersebut. Jangan kosongkan kolom ini kecuali memang ingin menghapus penugasan.

Memperbarui satu mahasiswa

Jika formulir Edit Mahasiswa tersedia pada akun Anda, cari mahasiswa berdasarkan NIM, buka edit, pilih Dosen Wali/Pembimbing Akademik, lalu simpan. Bila tombol edit tidak ada, gunakan impor massal bila berwenang atau minta Admin Akademik memperbaruinya.

Setelah impor, cari beberapa mahasiswa sebagai sampel dan pastikan nama dosen PA sudah benar. Perubahan penugasan dapat mengirim notifikasi kepada dosen yang baru ditetapkan.

Penawaran Perkuliahan

16. Menyiapkan kelas dan jadwal kuliah

Penawaran kelas dibuat per semester. Pilihan mata kuliah pada formulir mengikuti mata kuliah yang tercantum di kurikulum aktif program studi.

Membuat kelas

  1. Buka Akademik → Pembagian Kelas & Jadwal. Pilih semester dan prodi pada filter agar daftar mudah diperiksa.
  2. Pilih Tambah Kelas, lalu tentukan Semester, Program Studi, dan Mata Kuliah. Jika mata kuliah tidak muncul, periksa status kurikulum dan keanggotaan mata kuliah di kurikulum aktif.
  3. Isi nama kelas (misalnya A), kapasitas, dan tingkat. Periksa agar nama kelas tidak membingungkan mahasiswa.
  4. Untuk tatap muka, pilih dosen pengampu, hari, jam mulai/selesai, dan ruangan. Untuk non-tatap muka, dosen/jadwal/ruangan tidak diperlukan.
  5. Jika kelas dipakai lintas prodi atau beberapa mata kuliah, aktifkan opsi kelas gabungan, pilih mata kuliah tambahan, dan atur kuota bila diperlukan.
  6. Simpan dan tangani pesan bentrok jadwal bila sistem menampilkannya. Tinjau kembali kapasitas serta rincian kelas di tabel.

Impor dan pemeriksaan jadwal

  • Gunakan Template/Excel pada halaman ini untuk membuat banyak kelas. Pertahankan format kolom dan nilai referensi sesuai template.
  • Periksa kelas per semester, prodi, mata kuliah, dosen, jadwal, ruangan, dan kuota setelah impor.
  • Jangan menonaktifkan atau menghapus kelas yang sudah dipilih mahasiswa tanpa koordinasi. Atur pengganti dan informasikan perubahan.
  • Mahasiswa hanya dapat memilih kelas yang ditawarkan; kuota yang habis atau kelas yang tidak aktif dapat membatasi pilihan.

Checklist sebelum KRS dibuka: semester aktif benar, kurikulum sudah siap, kelas tersedia, dosen pengampu dan jadwal benar, kapasitas sesuai, serta tidak ada jadwal bentrok.

KRS dan Perwalian

17. Mengelola dan meninjau KRS

Kaprodi/Sekprodi dengan akses yang sesuai dapat memantau pengajuan KRS prodi. Persetujuan akademik dilakukan oleh dosen wali/admin sesuai kewenangan; Kaprodi dapat menandatangani KRS yang sudah disetujui jika tombol tersedia.

Mencari dan membuka KRS

  1. Buka Akademik → KRS & Perwalian. Pilih semester, prodi, status, atau cari NIM/nama.
  2. Untuk membuat KRS atas nama mahasiswa, pilih Buat KRS, pastikan semester yang dipilih benar, cari mahasiswa aktif, lalu pilih mahasiswa dan buat KRS.
  3. Buka detail KRS. Periksa identitas mahasiswa, prodi, semester, dosen wali, total SKS, dan daftar mata kuliah/kelas.
  4. Jika KRS masih DRAFT atau REJECTED dan Anda memiliki hak kelola, mata kuliah dapat ditambahkan atau dihapus. Pilih kelas yang sesuai untuk setiap mata kuliah.

Review pengajuan dan tanda tangan Kaprodi

  • SUBMITTED: menunggu review. Dosen wali yang ditugaskan atau admin yang berwenang dapat menyetujui atau menolak.
  • Sebelum menyetujui, periksa beban SKS, kesesuaian mata kuliah/kelas dengan kurikulum, dan catatan mahasiswa. Jika menolak, isi alasan yang jelas agar mahasiswa tahu perbaikannya.
  • APPROVED: KRS sudah disetujui dosen wali. Kaprodi yang berwenang dapat menggunakan tombol tanda tangan bila status belum ditandatangani.
  • REJECTED: mahasiswa perlu memperbaiki KRS sesuai catatan dan mengajukan ulang. Periksa perubahan sebelum review berikutnya.

Sistem menolak submit jika jadwal kelas mahasiswa bertabrakan; halaman detail menampilkan pasangan mata kuliah, kelas, hari, dan jam. Minta mahasiswa mengganti kelas atau menghapus pilihan yang konflik. Jangan menyetujui berdasarkan tangkapan layar saja.

Status umum: DRAFT (disusun), SUBMITTED (menunggu persetujuan), APPROVED (disetujui), REJECTED (perlu perbaikan), dan CANCELLED (dibatalkan). Selalu periksa status terbaru pada detail KRS.

Pengajuan surat

Kendala Aplikasi

20. Troubleshooting dan penyegaran cache

ASC terus mendapat perbaikan dan penambahan fitur. Browser atau aplikasi terpasang terkadang masih menggunakan berkas lama. Simpan pekerjaan terlebih dahulu, pastikan internet aktif, lalu coba langkah berikut.

Laptop atau komputer

Hard refresh

  • Windows/Linux, Chrome/Edge/Firefox: tekan Ctrl + Shift + R atau Ctrl + F5.
  • macOS: tekan Command + Shift + R.
  • Atau tahan tombol muat ulang dan pilih Empty cache and hard reload pada Chrome/Edge DevTools.

Hapus data situs ASC

  1. Buka ASC dan klik ikon kontrol situs di kiri alamat.
  2. Pilih Site settings/Pengaturan situs, lalu Delete/Clear data.
  3. Tutup semua tab/jendela ASC, buka kembali alamat, lalu masuk ulang.

Smartphone

  • Android Chrome: buka Chrome → menu ⋮ → History/Riwayat → Clear browsing data/Hapus data penjelajahan. Pilih cache; pilih cookies/data situs bila perlu, lalu hapus. Untuk ASC saja: Pengaturan Android → Aplikasi → Chrome → Penyimpanan → Kelola ruang/data situs (nama menu bervariasi) → cari asc.aljawami.ac.id → hapus data.
  • Android PWA: tutup aplikasi ASC sepenuhnya, buka kembali saat online, lalu tarik layar ke bawah untuk memuat ulang. Jika masih lama, hapus data situs ASC dari Chrome; buka kembali ASC dan pasang ulang ikon layar utama bila diperlukan.
  • iPhone/iPad Safari: Settings/Pengaturan → Apps → Safari (atau Safari pada pengaturan) → Advanced/Lanjutan → Website Data/Data Situs → cari aljawami.ac.id/ASC → Delete, atau pilih Clear History and Website Data. Menu dapat berbeda menurut versi iOS.
  • iPhone PWA: tutup ASC dari pengalih aplikasi, buka kembali setelah cache Safari dibersihkan. Jika tetap bermasalah, hapus ikon web dari layar utama, buka ASC di Safari, lalu tambahkan kembali.

Cookies/data situs mengeluarkan Anda dari akun. Pastikan kata sandi diketahui. Simpan atau kirim formulir yang belum selesai; menghapus data dapat menghilangkan sesi login, preferensi, atau data sementara.

Jika masalah berlanjut

Periksa koneksi dan coba browser terbaru. Catat menu, waktu, pesan kesalahan, serta langkah yang memunculkan masalah; sampaikan kepada admin ASC/Admin Akademik. Jangan mengirim kata sandi, kode login, atau data pribadi yang tidak diperlukan.
